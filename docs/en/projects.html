USD/TWD Exchange Rate Forecast Model

A medium-horizon forecasting framework for USD/TWD combining macro fundamentals and market microstructure signals.

Objective

  • Forecast 1-week to 1-month USD/TWD direction and volatility.
  • Provide explainable factor attribution for each forecast.

Data Inputs

  • Taiwan and US rate differentials.
  • DXY, risk sentiment, and regional FX basket.
  • Taiwan export orders, PMI surprises, and foreign equity flow.

Modeling Stack

  1. Baseline: regularized linear model (Elastic Net).
  2. Nonlinear layer: gradient boosting for interaction terms.
  3. Regime switch: hidden Markov model for low/high-volatility states.

Signal Equation

A stylized prediction equation:

\[ \hat{\Delta s}_{t+1} = \alpha + \sum_{k=1}^{K} w_k x_{k,t} + g(x_t) \]

where \(x_{k,t}\) is macro/market feature \(k\) and \(g(\cdot)\) captures nonlinear interactions.

Dual Moving Average Strategy Research

Quantitative research on trading signals from moving average crossovers, exploring trend reversals and momentum continuation in financial markets.

Strategy Core Logic

The dual moving average strategy is rooted in classical technical analysis: the short-term moving average captures recent market momentum, while the long-term moving average represents the primary market trend. When the short-term average crosses the long-term average, it signals a change in market momentum, generating a trading signal.

Buy Signal: 20-day MA crosses above 60-day MA (Golden Cross) \[MA_{20}(t) > MA_{60}(t) \text{ and } MA_{20}(t-1) \leq MA_{60}(t-1)\]

Sell Signal: 20-day MA crosses below 60-day MA (Death Cross) \[MA_{20}(t) < MA_{60}(t) \text{ and } MA_{20}(t-1) \geq MA_{60}(t-1)\]

Financial Theory Foundation

  1. Market Trend Hypothesis: Markets exhibit identifiable trends rather than pure random walks. Moving averages serve as trend filters, smoothing short-term noise.

  2. Momentum Effects: Empirical research shows both short-term momentum reversals and medium-term momentum continuation. Moving average crossovers capture these inflection points.

  3. Transaction Cost Realism: Real trading incurs commissions (0.1%) and slippage (0.05%). Incorporating these costs is essential for validating practical viability.

The Purpose of Backtesting

Backtesting is not an end goal but a method to validate strategy effectiveness. Historical evaluation addresses:

  • Signal Quality: Do identified crossovers capture actual trend reversals?
  • Risk-Adjusted Returns: True performance under risk management constraints (Sharpe ratio).
  • Practical Feasibility: Do excess returns persist after deducting trading costs?
  • Robustness Across Markets: How does strategy perform across different assets and periods?

Strategy Implementation Essentials

# Core logic for moving average crossover signals
def generate_signal(close_prices, short_window=20, long_window=60):
    """
    Generate moving average crossover signals.
    
    Parameters:
        close_prices: Historical closing price series
        short_window: Short-term MA period (days)
        long_window: Long-term MA period (days)
    
    Returns:
        signal: 1=Buy, -1=Sell, 0=No signal
    """
    ma_short = close_prices.rolling(window=short_window).mean()
    ma_long = close_prices.rolling(window=long_window).mean()
    
    # Identify crossover points
    crossover = (ma_short > ma_long) & (ma_short.shift(1) <= ma_long.shift(1))
    crossunder = (ma_short < ma_long) & (ma_short.shift(1) >= ma_long.shift(1))
    
    signal = pd.Series(0, index=close_prices.index)
    signal[crossover] = 1    # Golden cross
    signal[crossunder] = -1  # Death cross
    
    return signal

Quantitative Investing & Asset Pricing Model

Build a rigorous asset pricing framework for large-cap tech stocks (semiconductor leaders, global market cap titans), conducting deep valuation analysis and momentum trading strategies.

Core Objectives

Construct a multi-layered asset evaluation framework that combines financial theory with data-driven methods, providing principled entry/exit decisions for systematic traders and investment analysts.

Modeling Framework

1. Relative Valuation Layer

Bond-Stock Relative Value:

Compute fair equity price under risk-free rates using duration-based methods to compare debt and equity returns:

\[P_{fair} = \frac{EPS \times (1 + g)}{r - g}\]

where: - \(EPS\) = Earnings Per Share - \(g\) = Long-term growth rate - \(r\) = Required rate of return

Internal Rate of Return (IRR) Analysis:

Derive intrinsic company value from historical cash flows to identify overvalued or undervalued assets:

\[\sum_{t=1}^{T} \frac{CF_t}{(1+IRR)^t} = P_0\]

where \(CF_t\) is the cash flow in period \(t\) and \(P_0\) is the current stock price.

2. Factor Model Decomposition Layer

Fama-French Three-Factor Model:

\[R_i - R_f = \alpha + \beta_m (R_m - R_f) + \beta_s SMB + \beta_v HML + \epsilon_i\]

Factor Definitions: - \(R_m - R_f\) = Market risk premium - \(SMB\) = Size factor (small-cap minus large-cap) - \(HML\) = Value factor (high B/P minus low B/P)

Momentum Factor:

Identify time windows where price trends persist or revert, used to predict short-term excess returns:

\[MOM_t = \sum_{j=1}^{J} w_j \times R_{t-j}\]

3. Monte Carlo Simulation Layer

Use stochastic models to simulate stock price trajectories, assess extreme scenario risks and opportunities:

\[S_t = S_{t-1} \exp\left(\left(\mu - \frac{\sigma^2}{2}\right)\Delta t + \sigma \sqrt{\Delta t} Z_t\right)\]

where \(Z_t \sim N(0,1)\) is a random normal variable, running 10,000+ path simulations.

4. Deep Financial Statement Analysis

Multi-Year Trend Analysis: - Revenue Compound Annual Growth Rate (CAGR) - Gross margin / Operating margin trends - Free cash flow growth and quality

DuPont Analysis (ROE Decomposition):

\[ROE = \frac{Net\ Income}{Sales} \times \frac{Sales}{Total\ Assets} \times \frac{Total\ Assets}{Shareholders'\ Equity}\]

Strategy Implementation Logic

class QuantitativeValuationModel:
    """Quantitative Asset Pricing Model"""
    
    def __init__(self, ticker: str, lookback_years: int = 5):
        self.ticker = ticker
        self.lookback_years = lookback_years
        self.financials = None
        self.prices = None
    
    def compute_intrinsic_value(self) -> dict:
        """
        Calculate intrinsic value (multiple approaches)
        
        Methods:
        1. DCF (Discounted Cash Flow)
        2. P/E Relative valuation
        3. P/B (Price-to-Book)
        4. PEG (Growth-adjusted)
        """
        dcf_value = self.discounted_cash_flow()
        pe_value = self.relative_valuation()
        
        return {
            'dcf': dcf_value,
            'relative': pe_value,
            'fair_value': (dcf_value + pe_value) / 2
        }
    
    def factor_decomposition(self) -> pd.DataFrame:
        """Factor attribution analysis"""
        factors = pd.DataFrame({
            'market_beta': self.calculate_beta(),
            'size_factor': self.calculate_smb(),
            'value_factor': self.calculate_hml(),
            'momentum': self.calculate_momentum()
        })
        return factors
    
    def monte_carlo_simulation(self, 
                             n_simulations: int = 10000,
                             periods: int = 252) -> np.ndarray:
        """Monte Carlo path simulation"""
        S = np.zeros((n_simulations, periods))
        S[:, 0] = self.current_price
        
        for t in range(1, periods):
            Z = np.random.standard_normal(n_simulations)
            S[:, t] = S[:, t-1] * np.exp(
                (self.mu - self.sigma**2 / 2) / 252 + 
                self.sigma * np.sqrt(1/252) * Z
            )
        
        return S
    
    def generate_signal(self) -> str:
        """Generate trading signal"""
        current_price = self.prices[-1]
        fair_value = self.compute_intrinsic_value()['fair_value']
        margin_of_safety = 0.15  # 15% margin of safety
        
        if current_price < fair_value * (1 - margin_of_safety):
            return 'BUY'
        elif current_price > fair_value * (1 + margin_of_safety):
            return 'SELL'
        else:
            return 'HOLD'

美元/台幣匯率預測模型

結合宏觀基本面與市場微觀結構信號的中期預測框架。

目標

  • 預測 1 週至 1 個月的美元/台幣方向與波動率。
  • 為每個預測提供可解釋的因子歸因。

數據輸入

  • 台灣與美國利率差異。
  • DXY、風險情緒與區域外匯籃子。
  • 台灣出口訂單、PMI 驚喜與外資股票流。

建模技術棧

  1. 基線模型：正則化線性模型（Elastic Net）。
  2. 非線性層：梯度提升機處理交互項。
  3. 制度轉換：隱藏馬可夫模型處理低/高波動率狀態。

信號方程

預測方程式：

\[ \hat{\Delta s}_{t+1} = \alpha + \sum_{k=1}^{K} w_k x_{k,t} + g(x_t) \]

其中 \(x_{k,t}\) 是宏觀/市場特徵 \(k\)，\(g(\cdot)\) 捕捉非線性交互。

雙均線策略量化研究

利用技術分析中的移動平均線交叉信號，研究市場趨勢反轉與動能延續的量化交易策略。

策略核心邏輯

雙均線策略基於技術分析的經典原理：短期移動平均線反映近期市場動能，長期移動平均線代表市場主要趨勢。當短期平均線穿越長期平均線時，代表市場動能變化，形成交易信號。

買入信號：20日均線向上穿越60日均線（黃金交叉） \[MA_{20}(t) > MA_{60}(t) \text{ and } MA_{20}(t-1) \leq MA_{60}(t-1)\]

賣出信號：20日均線向下穿越60日均線（死亡交叉） \[MA_{20}(t) < MA_{60}(t) \text{ and } MA_{20}(t-1) \geq MA_{60}(t-1)\]

金融理論基礎

  1. 市場趨勢性：假設市場存在可識別的趨勢，而非完全隨機遊走。移動平均線作為趨勢過濾器，平滑短期噪聲。

  2. 動能效應：研究表明存在短期動能反轉與中期動能延續的現象。雙均線的交叉點捕捉這些轉折。

  3. 交易成本考量：真實交易環境中的手續費 (0.1%) 和滑點 (0.05%) 會顯著影響策略績效。納入成本模擬是驗證策略可行性的關鍵。

回測框架的意義

回測不是目的，而是驗證策略有效性的方法。通過歷史數據評估：

  • 信號品質：識別的交叉點是否能抓住實際的趨勢反轉。
  • 風險調整收益：策略在風險管理下的真實績效（Sharpe 比率）。
  • 實踐可行性：扣除交易成本與滑點後，策略是否仍有超額收益。
  • 不同市場環境：策略在不同股票、時期的魯棒性。

策略實現要點

# 策略信號生成的核心邏輯
def generate_signal(close_prices, short_window=20, long_window=60):
    """
    計算移動平均線交叉信號
    
    參數:
        close_prices: 歷史收盤價序列
        short_window: 短期均線窗口（天數）
        long_window: 長期均線窗口（天數）
    
    返回:
        signal: 1=買入, -1=賣出, 0=無信號
    """
    ma_short = close_prices.rolling(window=short_window).mean()
    ma_long = close_prices.rolling(window=long_window).mean()
    
    # 識別交叉點
    crossover = (ma_short > ma_long) & (ma_short.shift(1) <= ma_long.shift(1))
    crossunder = (ma_short < ma_long) & (ma_short.shift(1) >= ma_long.shift(1))
    
    signal = pd.Series(0, index=close_prices.index)
    signal[crossover] = 1   # 黃金交叉
    signal[crossunder] = -1 # 死亡交叉
    
    return signal

關鍵研究問題

  1. 參數優化：20/60 的均線周期組合是否最優？不同標的是否需要調整？

  2. 風險管理：在單一策略基礎上，如何加入止損機制或動態頭寸管理？

  3. 市場適應性：策略在不同市場狀態（趨勢市 vs 盤整市）的表現差異。

  4. 交易成本影響：手續費與滑點對不同交易頻率策略的影響程度。

延伸研究方向

  • 多因子模型：加入 RSI、MACD 等動量指標的確認。
  • 機器學習優化：利用歷史數據找出最優的參數組合。
  • 風險平價策略：根據不同標的的波動率動態調整頭寸。

量化投資與資產定價模型

為大型科技股（半導體龍頭、全球市值前段班企業）構建嚴謹的資產定價模型，進行深度估值分析與動量交易策略。

核心目標

構建一個多層次的資產評估框架，將金融理論與數據驅動方法結合，為系統性交易員與投資分析師提供有原則的進出場決策。

建模框架

1. 相對價值評估層

債券-股票相對價值：

計算無風險收益率下的公平股價，使用持續期（Duration）方法比較債權與股權收益：

\[P_{fair} = \frac{EPS \times (1 + g)}{r - g}\]

其中： - \(EPS\) = 每股盈餘 - \(g\) = 長期成長率 - \(r\) = 必要回報率

內部收益率（IRR）分析：

基於歷史現金流推導公司內在價值，用於識別被高估或低估的資產：

\[\sum_{t=1}^{T} \frac{CF_t}{(1+IRR)^t} = P_0\]

其中 \(CF_t\) 是第 \(t\) 期現金流，\(P_0\) 是當前股價。

2. 因子模型分解層

Fama-French 三因子模型：

\[R_i - R_f = \alpha + \beta_m (R_m - R_f) + \beta_s SMB + \beta_v HML + \epsilon_i\]

因子定義： - \(R_m - R_f\) = 市場風險溢價 - \(SMB\) = 規模因子（小公司 - 大公司） - \(HML\) = 價值因子（高 B/P - 低 B/P）

動量因子：

識別股價走勢延續或反轉的時間窗口，用於預測短期超額收益：

\[MOM_t = \sum_{j=1}^{J} w_j \times R_{t-j}\]

3. 蒙地卡羅模擬層

使用隨機模型模擬股價軌跡，評估極端情景下的風險與機會：

\[S_t = S_{t-1} \exp\left(\left(\mu - \frac{\sigma^2}{2}\right)\Delta t + \sigma \sqrt{\Delta t} Z_t\right)\]

其中 \(Z_t \sim N(0,1)\) 為隨機正態變數，進行 10,000+ 路徑模擬。

4. 財務報表深度分析

多年期趨勢分析： - 營收複合增長率 (CAGR) - 毛利率 / 營業利率變化趨勢 - 自由現金流成長與品質

杜邦分析（ROE 拆解）：

\[ROE = \frac{淨利潤}{銷售收入} \times \frac{銷售收入}{總資產} \times \frac{總資產}{股東權益}\]

class QuantitativeValuationModel:
    """量化資產定價模型"""
    
    def __init__(self, ticker: str, lookback_years: int = 5):
        self.ticker = ticker
        self.lookback_years = lookback_years
        self.financials = None
        self.prices = None
    
    def compute_intrinsic_value(self) -> dict:
        """
        計算內在價值 (多種方法)
        
        方法：
        1. DCF 貼現現金流
        2. P/E 相對估值
        3. P/B 價淨比
        4. PEG 成長調整
        """
        dcf_value = self.discounted_cash_flow()
        pe_value = self.relative_valuation()
        
        return {
            'dcf': dcf_value,
            'relative': pe_value,
            'fair_value': (dcf_value + pe_value) / 2
        }
    
    def factor_decomposition(self) -> pd.DataFrame:
        """因子歸因分析"""
        factors = pd.DataFrame({
            'market_beta': self.calculate_beta(),
            'size_factor': self.calculate_smb(),
            'value_factor': self.calculate_hml(),
            'momentum': self.calculate_momentum()
        })
        return factors
    
    def monte_carlo_simulation(self, 
                             n_simulations: int = 10000,
                             periods: int = 252) -> np.ndarray:
        """蒙地卡羅路徑模擬"""
        S = np.zeros((n_simulations, periods))
        S[:, 0] = self.current_price
        
        for t in range(1, periods):
            Z = np.random.standard_normal(n_simulations)
            S[:, t] = S[:, t-1] * np.exp(
                (self.mu - self.sigma**2 / 2) / 252 + 
                self.sigma * np.sqrt(1/252) * Z
            )
        
        return S
    
    def generate_signal(self) -> str:
        """生成交易信號"""
        current_price = self.prices[-1]
        fair_value = self.compute_intrinsic_value()['fair_value']
        margin_of_safety = 0.15  # 15% 安全邊際
        
        if current_price < fair_value * (1 - margin_of_safety):
            return 'BUY'
        elif current_price > fair_value * (1 + margin_of_safety):
            return 'SELL'
        else:
            return 'HOLD'

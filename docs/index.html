關於我

我是一位經濟學家與數據工程師，具備總體經濟分析、外匯市場動態與自動化金融報告的深厚專業知識。我的工作融合深層經濟理論與實踐量化技能。

研究背景：根植於總體經濟理論與政策分析，專注於收益率曲線、貨幣傳導機制與不同經濟週期下的跨資產估值。

量化專業：熟練運用 Python 與 R 進行金融建模——包括 IRR 計算、Duration 分析與因子模型構建。我專精於構建健壯的數據管道，將原始市場數據轉化為可操作的洞察。

開發思維：現代 AI 輔助開發（Vibe Coding）的實踐者，能夠快速將研究想法轉化為生產級別的分析系統。我善用自動化來最大化研究效率。

精選專案

📊 外匯預測與自動化系統

問題 → 方法 → 結果

開發一個數據驅動的系統，使用總體經濟指標和中央銀行數據來預測和追踪新台幣與日圓匯率波動。

技術亮點： - 整合美國聯邦準備局 FRED API 與中央銀行數據源 - 使用 Python 構建自動化 ETL 管道，進行每日數據收集與驗證 - 生成包含圖表與統計分析的機器可讀日報告 - 部署於 GitHub Pages，實時監控外匯趨勢

影響： 透過端對端自動化減少 ~90% 的手動分析時間。系統每個交易日自主生成預測與報告。

Python yfinance Pandas ETL GitHub Pages

💰 量化投資與資產定價模型

問題 → 方法 → 結果

為大型科技股（半導體龍頭、全球市值前段班企業）構建嚴謹的資產定價模型，進行深度估值分析。

技術亮點： - 實施 Duration 與 IRR 計算進行債券股票相對價值評估 - 構建因子模型進行股價分解與動量分析 - 開發策略回測框架，含蒙地卡羅模擬 - 分析多年期財務報表推導內在估值

影響： 提供有數據支持的資產配置信號，包含可量化的風險指標。為系統性交易員提供有原則的進出場決策。

📈 每日財務報告系統

問題 → 方法 → 結果

創建一個自動化的專業報告系統，每日追踪 16 項全球市場資產，提供精美視覺化與多語言 PDF。

技術亮點： - 設計雙子圖布局，含價格趨勢、日期標記與漲跌著色 - 實現基於 LaTeX 的 PDF 生成，具備國際化支持（英文/中文） - 添加專業水印和作者品牌至所有報告 - 構建日期版本化存儲系統，用於歷史報告存檔與存取

影響： 每日生成精拋光、出版就緒的報告，零手動介入。讓利益關係人以專業呈現追踪全球市場。
